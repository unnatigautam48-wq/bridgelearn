# BridgeLearn

BridgeLearn is a multilingual AI learning companion that explains lessons,
checks understanding, and recommends personalized practice.

## Features

- English and Hindi learning support
- Source-grounded AI explanations
- Adaptive quiz
- Weak-concept detection
- Personalized practice recommendations
- .txt and .md lesson upload
- 60-second demo mode

## Demo Flow

Start demo → Ask a question → Take the quiz →
Miss a concept → Receive personalized practice.

## Limitations

PDF upload is not supported in the current MVP.
BridgeLearn is a learning aid, not a teacher replacement.

Developed and deployed using the Manus WebDev environment.
